Data Cleanup Automation Demo

這是一個純前端互動 Demo，展示如何將格式不一致的人工資料，透過自動化清洗、規則判斷與 Payload 產生，轉換成可用於後續 API 串接、報表或審批流程的標準資料。

Services

這個 Demo 對應哪些實際服務？

以下為此互動展示所對應的企業自動化服務類型。

Excel / CSV 報表自動化

將人工整理的資料轉為可重複執行的規則

API / Webhook 串接格式設計

將清洗後資料轉成可送往 Webhook、Google Sheets 或外部系統的標準 Payload；正式串接需依實際 API、權限與後端安全設計評估。

內部 Dashboard

讓主管快速看到異常、風險與待審核項目

稽核紀錄

保留每一步處理紀錄，降低交接與追查成本

LINE 通知卡片預覽

展示流程異常或高風險項目如何轉為通知卡片；正式發送需透過 LINE Messaging API 與後端或中繼服務處理，不在前端暴露 token。
